# Quick Translator

Компактный светлый переводчик EN ↔ RU. Перевод запускается автоматически после короткой паузы при вводе, работает офлайн и не отправляет текст в интернет. Последние исходный текст и перевод восстанавливаются при повторном запуске.

Для обычного использования скачайте `QuickTranslator-Windows-x64.zip` в разделе Releases, распакуйте и откройте `QuickTranslator.exe`. Установка Python не нужна. Первый запуск скачает модели EN ↔ RU с сервера Argos (примерно 370 МБ); после этого перевод работает без интернета. Windows 10/11 x64.

Вводите или вставляйте текст — перевод появится автоматически. Enter запускает перевод немедленно, Shift+Enter добавляет строку, Esc скрывает окно. Повторный запуск или значок в трее показывают/скрывают окно.

`install.ps1` назначает кнопку Калькулятор для текущего пользователя и добавляет ярлык в меню Пуск.
Исходные значения сохраняются в `calculator-key-backup.clixml`; `uninstall.ps1` восстанавливает их.
Некоторые клавиатуры обрабатывают кнопку собственным драйвером: для них может потребоваться настройка в программе производителя.

Клавишу Калькулятор можно назначить скриптом `install.ps1`; откат доступен через `uninstall.ps1`. Переводческие модели скачиваются напрямую у Argos и не включены в релизный архив.

Для запуска из исходников установите зависимости из `requirements.txt` и модели Argos для en→ru и ru→en. Публичный релиз для Windows собирается автоматически при отправке тега `v*`.
