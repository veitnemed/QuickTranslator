# Third-party components

The Windows release bundles Argos Translate, CTranslate2, PySide6/Qt, and their dependencies. The Argos EN ↔ RU translation model packages are downloaded directly from the Argos package source on first launch and are not redistributed in this project. Their upstream package metadata, README attribution, and licensing details remain with those downloads. The upstream model reference is https://community.libretranslate.com/t/new-argos-model-en-ru-and-ru-en/872/.

The software component licenses are provided in the Python package metadata and Qt deployment files inside the release archive.
